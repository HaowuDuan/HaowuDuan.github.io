Reinforcement Learning · Technical Note

Reinforcement Learning

We use LLM fine-tuning as an example and context.

Introduction

Some basic definitions

We first identify the objects involved in reinforcement learning.

  1. The state at time t is St​.

  2. The action at time t is at​. It labels the transition from St​ to St+1​, whose probability is P(St+1​∣St​,at​).

  3. A stationary policy π is a global rule that assigns a distribution of actions to each state. Associate the action at​ with the operator a^t​. Then

π^∣St​⟩​=∫dat​π(at​∣St​)a^t​∣St​⟩≡π^(St​)∣St​⟩,​(1)

where π^(St​)=∫dat​π(at​∣St​)a^t​. For a discrete action space, the integral is replaced by a sum.

Let πθ​ denote a policy parameterized by θ. For the trajectory

T=(S0​,a0​,S1​,a1​,…,aN−1​,SN​),​(2)

where N is the number of transitions, the probability induced by πθ​ is

P(T∣πθ​)=ρ(S0​)i=0∏N−1​P(Si+1​∣Si​,ai​)πθ​(ai​∣Si​),​(3)

where ρ(S0​) is the initial-state distribution. This is the path measure.

Reward and return

The reward at step i is

ri​=R(ai​,Si​,Si+1​),​(4)

Let 0≤γ≤1 be the discount factor. The total return along T is

G0​[T]=i=0∑N−1​γiri​.​(5)

The return remaining from time t is

Gt​=i=t∑N−1​γi−tri​.​(6)

The expected return is

J(θ)=∫DSDaP(T∣πθ​)G0​[T]=⟨G0​[T]⟩T∼πθ​​.​(7)

Here DSDa denotes the sum or integral over all state–action paths.

Fixing the initial state gives the on-policy value function,

Vπ(S)=⟨G0​[T]⟩T∼π;S0​=S​.​(8)

The word “initial” refers to the path segment being averaged. At time t, the current state St​ is the initial state of the remaining path, so

Vπ(St​)=E[Gt​∣St​].​(9)

Fixing the initial state and action gives the Q function,

Qπ(S,a)=⟨G0​[T]⟩T∼π;S0​=S,a0​=a​.​(10)

Averaging over the first action recovers the value function:

Vπ(S)=∫daπ(a∣S)Qπ(S,a).​(11)

At time t, their difference is the advantage,

Aπ(St​,at​)=Qπ(St​,at​)−Vπ(St​).​(12)

Policy gradient

The optimal policy maximizes the expected return. At an interior optimum,

∇θ​J(θ)=0.​(13)

Assume that the reward function has no explicit θ dependence, so G0​[T] is fixed when a path is fixed. Using

∇θ​πθ​(at​∣St​)=πθ​(at​∣St​)∇θ​logπθ​(at​∣St​)​(14)

gives

∇θ​J(θ)=⟨G0​[T]∇θ​logP(T∣πθ​)⟩.​(15)

When ρ and P do not depend on θ,

∇θ​logP(T∣πθ​)=i=0∑N−1​∇θ​logπθ​(ai​∣Si​).​(16)

The corresponding surrogate loss is

LPG​(θ)=−E[G0​[T]i=0∑N−1​logπθ​(ai​∣Si​)].​(17)

Here E is the average over sampled paths. Their returns are held fixed while differentiating the loss. The first derivative of Eq. (17) gives the sampled policy gradient; the surrogate and −J are not the same function and need not have the same higher derivatives.

The LLM Post-Training Problem

An LLM already defines a distribution over responses. For a prompt x and a response y=(y1​,…,yL​), identify

St​=(x,y<t​),at​=yt​,St+1​=(x,y≤t​).​(18)

Here πθ​(⋅∣St​) is the next-token distribution produced by the complete LLM. The action space is the vocabulary, and a complete response is a path of token actions. Which network parameters are included in θ is a separate implementation choice. Appending yt​ is a deterministic transition, so for the complete path T=(x,y),

P(T∣πθ​)=q(x)t=1∏L​πθ​(yt​∣x,y<t​),​(19)

where q is the prompt distribution and q(x) is its probability mass or density. The LLM supplies the policy and therefore the path measure. The post-training problem is to move probability mass toward paths that exhibit reasoning.

Let Cx​ be the set of responses that pass a specified reasoning criterion for prompt x. If this criterion can be evaluated exactly, then

Pθ​(C)=Ex∼q​​y∈Cx​∑​πθ​(y∣x)​.​(20)

Thus increasing reasoning capability means increasing the probability mass in Cx​. More generally, training uses a measurable sequence score R(x,y), supplied by a verifier, human preference, or learned reward model. It is treated as the complete-path return. Unless stated otherwise, LLM training in this note uses the undiscounted return γ=1. From this point onward, γ is therefore suppressed.

Section 1 indexed generic transitions from zero. Here tokens are indexed by t=1,…,L. The one-step reward rt​ is assigned after yt​ extends St​. Since St+1​ is determined by St​ and yt​, write

rt​Gt​​=R(St​,yt​),=i=t∑L​ri​.​(21)

Here L is the response length. If the score is assigned only after the last token, then rt​=Θ(t−L)R(x,y), where Θ(t−L)=0 for t<L and Θ(0)=1. This gives G1​=R(x,y). The value, action-value, and advantage functions become

Vπ(St​)Qπ(St​,yt​)Aπ(St​,yt​)​=E[Gt​∣St​],=E[Gt​∣St​,yt​],=Qπ(St​,yt​)−Vπ(St​).​(22)

At the first generation step, y<t​ is empty, so the fixed state in Vπ is the prompt. At later steps, it is the prompt together with the existing response prefix. The expectation is over tokens generated after that prefix. The objective is

JLLM​(θ)=Ex∼q,y∼πθ​(⋅∣x)​[R(x,y)].​(23)

If R(x,y)=1 for a response in Cx​ and zero otherwise, Eq. (23) is exactly Eq. (20). For a graded score, it is the expected measured quality. The objective increases reasoning only to the extent that R measures reasoning.

Assume that the scoring rule R is fixed during the policy update. Using Eq. (16),

∇θ​JLLM​(θ)=Ex∼q,y∼πθ​(⋅∣x)​[R(x,y)t=1∑L​∇θ​logπθ​(yt​∣x,y<t​)].​(24)

With the exact gradient, a learning rate η>0, and a sufficiently small step θ′=θ+η∇θ​JLLM​(θ),

JLLM​(θ′)=JLLM​(θ)+η∥∇θ​JLLM​(θ)∥2+O(η2).​(25)

This is the precise local improvement statement. In standard RL terminology, one path T sampled from P(T∣πθ​) is a rollout. For an LLM, it is one prompt and one generated response together with its reward. A finite batch of rollouts only estimates this gradient, so an individual update need not improve the measured objective.

For a batch of M sampled prompt–response paths, let m=1,…,M index a path, let Lm​ be its response length, and define Rm​=R(x(m),y(m)). The direct sampled loss is

LLLM-PG​(θ)=−M1​m=1∑M​Rm​t=1∑Lm​​logπθ​(yt(m)​∣x(m),y<t(m)​).​(26)

The sampled responses and scores are held fixed during differentiation. Computing the loss requires an LLM forward pass on each prompt–response pair, followed by the sum of its generated-token log-probabilities. Ordinary backpropagation then updates θ.

The remaining methods split according to the source of these responses. Online methods generate them from an evolving policy and use a policy-gradient estimator. Offline methods optimize the model on responses stored in a fixed dataset. Sections 3–5 develop the online branch; Section 6 compares online and offline training and then defines the offline objectives.

Online Policy-Gradient Methods

The online branch follows the policy gradient in Eqs. (15) and (16): increase the probability of sampled paths in proportion to their return. The equations below use the undiscounted LLM return fixed in Section 2.

REINFORCE

For the action ai​, split the complete return into rewards before and after that action:

G0​[T]=G<i​j=0∑i−1​rj​​​+Gi​.​(27)

The past return G<i​ and state Si​ are fixed before ai​ is sampled. Its contribution vanishes because Eai​∼πθ​​[∇θ​logπθ​(ai​∣Si​)]=0. The reward-to-go therefore keeps exactly the part of the return that ai​ can still affect. Equation (15) becomes

∇θ​J(θ)=⟨i=0∑N−1​Gi​∇θ​logπθ​(ai​∣Si​)⟩T∼πθ​​.​(28)

Equation (28) is the REINFORCE identity before baseline subtraction; a finite rollout average estimates its expectation. In LLM post-training, the reward is often assigned only after the complete response. Then every token receives the same sequence-level reward-to-go.

Baselines and advantage estimation

For any function ν(Si​) independent of the sampled action,

Eai​∼πθ​(⋅∣Si​)​[ν(Si​)∇θ​logπθ​(ai​∣Si​)]​=ν(Si​)∇θ​∫dai​πθ​(ai​∣Si​)=0.​(29)

The baseline changes variance but not the expected gradient:

∇θ​J(θ)=⟨i=0∑N−1​(Gi​−ν(Si​))∇θ​logπθ​(ai​∣Si​)⟩T∼πθ​​.​(30)

At state Si​, Vπ(Si​) is the expected reward-to-go before an action is fixed, while Qπ(Si​,ai​) is the expected reward-to-go after ai​ is fixed. Their difference Aπ(Si​,ai​)=Qπ(Si​,ai​)−Vπ(Si​) therefore asks whether ai​ is better or worse than the policy’s usual action at the same state. Choosing ν(Si​)=Vπ(Si​) gives the sampled estimate

Ai​=Gi​−Vπ(Si​).​(31)

A positive advantage increases the probability of ai​; a negative advantage decreases it. After baseline subtraction, the update depends on the return relative to what was expected from the same state.

The actor is the policy πθ​ defined in Section 1. It samples the actions, and updating θ changes the path measure P(T∣πθ​).

A critic is a computational emulator of the conditional path average, Vψ​(St​)≈Vπ(St​), with trainable parameters ψ. The quantity Vπ(St​) is mathematically defined, but evaluating it directly would require many continuations from the same state. The critic predicts this average with one forward pass. It does not define the reward, choose actions, or change the path measure.

For an LLM, St​=(x,y<t​), the action is the next token at​=yt​, and the actor is the complete policy network that produces πθ​(⋅∣St​). The actor–critic implementation used below also trains Vψ​(St​). Figure 1 shows a separate-model implementation.

After a rollout, the realized return Gt​ is computed from the observed rewards after state St​. It is one noisy sample of the conditional mean Vπ(St​). For a fixed state St​=s, let v be a scalar. Then

vargmin​E[(v−Gt​)2∣St​=s]=E[Gt​∣St​=s]=Vπ(s).​(32)

Therefore the critic can be trained by ordinary regression against sampled returns. Let Et​ denote the average over all valid token positions in the rollout batch. The critic loss is

LV​(ψ)=Et​[(Vψ​(St​)−Gt​)2].​(33)

For an LLM, one training example for the critic is therefore a prefix St​=(x,y<t​) paired with the return obtained by its sampled continuation. The individual return is the comparison target; averaging over many such examples makes the critic approach the conditional mean. This is the auxiliary optimization, not another policy optimization.

The two objectives need not be solved sequentially. The current critic is used to compute the advantages for a rollout batch, after which the actor loss and critic loss are usually optimized together or in alternating minibatch steps. The critic improves across rollout batches rather than being solved exactly before each actor update.

For the response-level reward defined in Section 2, set Vψ​(SL+1​)=0 after the response ends. The residual used by generalized advantage estimation (GAE) is then1

δt​={Vψ​(St+1​)−Vψ​(St​),R(x,y)−Vψ​(SL​),​1≤t<L,t=L.​​(34)

The first line asks whether adding a nonfinal token raises the predicted final score. The second line compares the realized response score with the score predicted before the final token.

More generally, rt​+Vψ​(St+1​) estimates Qπ(St​,at​), and subtracting Vψ​(St​) gives an estimated advantage. If Vψ​=Vπ,

E[δt​∣St​,at​]​=E[rt​+Vπ(St+1​)∣St​,at​]−Vπ(St​)=Qπ(St​,at​)−Vπ(St​)=Aπ(St​,at​).​(35)

GAE combines the residual at step t with the residuals at later steps:

AtGAE​=ℓ=0∑L−t​λℓδt+ℓ​,0≤λ≤1.​(36)

The parameter λ controls how many later residuals matter. At λ=0, AtGAE​=δt​. At λ=1, the sum telescopes to the sampled reward-to-go minus Vψ​(St​), assuming the value after termination is zero. GAE is one possible advantage estimator; the clipped update introduced next does not require it.

For fixed sampled paths and fixed advantage estimates At​, the surrogate loss is

LPG​(θ)=−E[t=1∑L​At​logπθ​(at​∣St​)].​(37)

Its gradient reproduces the sampled policy-gradient direction at the policy that generated the paths.

Importance sampling and policy reuse

Let θold​ be the model parameters used to generate a stored batch, and let θ be the parameters being optimized. Define pθ​(T)=P(T∣πθ​). The same path T generally has different probabilities under pθold​​ and pθ​. No path variable is transformed, so there is no coordinate Jacobian. The change of measure is the likelihood ratio

wt​(θ)wθ​(T)​≡πθold​​(at​∣St​)πθ​(at​∣St​)​,≡pθold​​(T)pθ​(T)​=t=0∏N−1​wt​(θ).​(38)

The initial-state distribution and transition probabilities are the same in the numerator and denominator of wθ​(T), so they cancel. Only the policy probabilities remain. Multiplying by wθ​(T) then gives the exact change of path measure:

J(θ)​=∫DSDapθ​(T)G0​[T]=∫DSDapθold​​(T)wθ​(T)G0​[T]=ET∼pθold​​​[wθ​(T)G0​[T]],​(39)

This permits path reuse, but large ratios make the estimate high-variance.

Proximal Policy Optimization

The motivation for proximal policy optimization (PPO) is computational efficiency [1]. Generating and scoring responses is expensive; reusing a stored rollout batch for several gradient updates is cheaper.

Equation (39) already gives the exact change of measure. For the current batch, let πold​=πθold​​ be the policy that generated the responses, and let πθ​ be the policy being updated. During batch reuse, πold​, the sampled states, and the advantages At​ are fixed; only πθ​ changes. PPO starts from the token-level conservative policy iteration (CPI) objective

JCPI​(θ)=Et​[wt​(θ)At​],​(40)

where wt​(θ) is the likelihood ratio in Eq. (38), and Et​ averages the valid token positions in the batch. The advantage is supplied by an estimator. The original PPO actor–critic algorithm used At​=AtGAE​ from Eq. (36).

At θ=θold​, Eq. (40) has the sampled policy-gradient direction. Repeated updates can move wt​(θ) far from one while the batch remains fixed. PPO regularizes Eq. (40) by clipping this favorable change. For ϵ>0, clip(w,a,b)=a for w<a, b for w>b, and w otherwise. The clipped objective is [1]

jtclip​(θ)JPPOclip​(θ)​={At​min(wt​(θ),1+ϵ),At​max(wt​(θ),1−ϵ),​At​≥0,At​<0,​=min(wt​(θ)At​,clip(wt​(θ),1−ϵ,1+ϵ)At​),=Et​[jtclip​(θ)].​(41)

The piecewise line is the operative rule. For At​≥0, it follows wt​At​ up to wt​=1+ϵ; the lower boundary is inactive. For At​<0, it follows the same term down to wt​=1−ϵ; the upper boundary is inactive. Thus PPO removes the gradient only after a token ratio has moved too far in the favorable direction. It does not hide movement in the unfavorable direction.

The second line is the compact form of the same rule. It gives jtclip​≤wt​At​, a pointwise lower bound on the sampled contribution, not on the true expected return. The choice of ϵ controls how far the batch is reused; clipping is not a convergence guarantee [4].

The reference policy πref​ is different from πold​. It is usually the initial supervised model and remains fixed throughout training. Let cV​≥0 weight the critic loss and let β≥0 weight the optional Kullback–Leibler (KL) penalty to πref​. The combined LLM training loss is [1, 2]

LPPO​(θ,ψ)=−JPPOclip​(θ)+cV​Et​[(Vψ​(St​)−Gt​)2]+βEt​[DKL​(πθ​(⋅∣St​)∥πref​(⋅∣St​))].​(42)

Equation (42) is minimized. Its three terms update the policy, fit the value emulator to the single target Gt​, and limit cumulative drift from the reference policy, respectively.

PPO is a battle-tested LLM post-training baseline. InstructGPT used PPO with a separate value function and one inner epoch per rollout batch [2]. NVIDIA’s current NeMo RL stack describes PPO as widely used and supports it at production scale [12]. Its PPO recipe is nevertheless much larger than Eq. (41): it includes a value model, optional critic warm-up, independent actor and critic update counts, KL control, and critic and policy diagnostics. Thus production PPO is rarely just the clipped objective from the original paper.

The practical limitation of vanilla PPO is not the likelihood ratio itself. The ratio is the correct local change-of-measure factor. The difficulty is the collection of approximations around it: finite rollout batches, fixed advantages during batch reuse, token-level rather than complete-path ratios, a learned critic, and clipping. The critic adds memory and optimization cost and can introduce value bias. Ratio clipping does not enforce a strict trust region [4]. For long responses with sparse terminal rewards, value bias and decay of the propagated reward signal can become important [10].

This cost motivated critic-free alternatives. A study of ordinary RLHF found that simpler REINFORCE-style estimators could outperform PPO while requiring less computation [5]. DeepSeekMath introduced group-relative policy optimization (GRPO) specifically to remove PPO’s value model [6], and DeepSeek-R1 subsequently used GRPO in its reasoning-training pipeline [7].

Removing the critic does not settle the stability problem. In the DAPO experiments, a naive GRPO run exhibited entropy collapse, reward noise, and training instability. DAPO added asymmetric clipping, dynamic sampling, token-level loss aggregation, and overlong-response shaping [8]. Qwen’s later group sequence policy optimization (GSPO) replaced token-level importance ratios and clipping by sequence-level versions and reported improved stability relative to GRPO, particularly for mixture-of-experts training [9]. These are reported results of the respective systems, not a universal ranking of the objectives.

The development has also moved back toward value-based methods. VAPO retains a critic but changes its initialization, targets, and advantage construction for long reasoning traces [11]. Its motivation is that a well-trained critic can provide token-level credit assignment that a single response score cannot, while the preceding failure analysis shows why an ordinary critic may fail [10]. The resulting practical picture is therefore conditional: vanilla PPO is established but high-maintenance; a carefully trained critic may help long-horizon credit assignment; and GRPO is cheaper when several responses can be scored directly. Direct preference optimization (DPO) addresses a different regime in which training uses a fixed preference dataset rather than new online responses.

GRPO keeps online generation, the old-policy likelihood ratio, and a PPO-style clipped actor update, but replaces the value emulator by a comparison among several complete responses to the same prompt.

Group-Relative Policy Optimization

Group-relative advantage

For one prompt x, let K≥2 be the number of complete responses sampled from the frozen policy πold​, let k=1,…,K index a response, and let Lk​ be its length:

y(k)Rk​​∼πold​(⋅∣x),=R(x,y(k)).​(43)

GRPO does not estimate Vπ. It instead compares the K scores for the same prompt. With a numerical stabilizer εR​>0, the supplied implementation uses the sample standard deviation:

RsR​AkGRPO​​=K1​j=1∑K​Rj​,=K−11​j=1∑K​(Rj​−R)2​,=sR​+εR​Rk​−R​.​(44)

The token-level clipped objective

For response k, define St(k)​=(x,y<t(k)​). The probability ratio for token yt(k)​ is

wkt​(θ)=πold​(yt(k)​∣St(k)​)πθ​(yt(k)​∣St(k)​)​.​(45)

The same response-level advantage AkGRPO​ weights every token in that response. GRPO maximizes the length-normalized objective

JGRPOclip​(θ)=K1​k=1∑K​Lk​1​t=1∑Lk​​min(wkt​(θ)AkGRPO​,clip(wkt​(θ),1−ϵ,1+ϵ)AkGRPO​).​(46)

The supplied implementation also compares the current policy with the fixed reference policy. For the sampled token yt(k)​, let pkt​=πθ​(yt(k)​∣St(k)​) and qkt​=πref​(yt(k)​∣St(k)​). The sampled KL penalty is Dkt​=qkt​/pkt​−log(qkt​/pkt​)−1≥0 [6]. Its conditional expectation over yt(k)​∼πθ​(⋅∣St(k)​) is DKL​(πθ​(⋅∣St(k)​)∥πref​(⋅∣St(k)​)).2

During later reuse of the same batch, its tokens come from πold​, not exactly from πθ​. The expectation identity in the footnote then no longer holds exactly for the stored batch, so its mean is only a local estimate of the current-policy KL.

Let β≥0 control this penalty. The complete loss minimized by the implementation is

LGRPO​(θ)​=−JGRPOclip​(θ)+Kβ​k=1∑K​Lk​1​t=1∑Lk​​Dkt​.​(47)

Thus GRPO changes the source of the advantage estimate; its actor update is still PPO-style. The three methods differ in the weight multiplying ∇θ​logπθ​:

REINFORCE:Ak​PPO with critic:At​GRPO:Ak​​=Rk​,=AtGAE​,=sR​+εR​Rk​−R​.​(48)

Online and Offline Training

Equation (7) averages over all possible paths. In practice, we replace this path integral by an average over a finite batch. Let n label an optimization step, let M be the number of paths in its batch, and let m=1,…,M index a path. Write

Bn​Tn(m)​​={Tn(1)​,…,Tn(M)​},∼qn​(T).​(49)

Here Bn​ is the batch and qn​(T) is the probability distribution from which its paths are drawn. The subscript n allows this distribution to change during training. Let F(T) be any quantity computed from a path, such as its return or its loss. Its expectation is estimated by

Eqn​​[F]=M1​m=1∑M​F(Tn(m)​).​(50)

This is the finite-batch version of the path integral. To distinguish offline and online training, define qdata​(T) as the distribution of paths in a fixed dataset, and define pθn​​(T)=P(T∣πθn​​) as the path distribution generated by the policy at step n. Then

offline:qn​(T)online:qn​(T)​=qdata​(T),=pθn​​(T).​(51)

Offline training samples stored paths from qdata​, which does not change when the model changes. Online training samples new paths from pθn​​, so changing the model changes the paths available for later updates.

The same distinction appears in the objectives. Let Ξ denote one stored training record: a single supervised response, or a pair of response paths with their preference label. Let qdata​(Ξ) be the fixed distribution of these records, and let ℓθ​(Ξ) be the loss assigned to one record. Then

Loff​(θ)J(θ)​=EΞ∼qdata​​[ℓθ​(Ξ)],=ET∼pθ​​[G0​[T]].​(52)

In the offline objective, θ changes the loss but not the stored records. In the online objective, G0​[T] is the complete-path return from Eq. (5), and θ changes the path distribution pθ​(T). Supervised fine-tuning and DPO use the first form; PPO and GRPO use the second.

For LLM training, online means that responses are generated during training. A batch is on-policy only for the policy that generated it. After that policy is updated, reuse of the batch requires the likelihood ratio in Eq. (38).

Supervised fine-tuning

Let qSFT​(x,y) be the empirical distribution of a fixed prompt–response dataset. Supervised fine-tuning (SFT) minimizes

LSFT​(θ)​=−E(x,y)∼qSFT​​[logπθ​(y∣x)]=−E(x,y)∼qSFT​​[t=1∑L​logπθ​(yt​∣x,y<t​)].​(53)

This increases the probability of the demonstrated paths.

Preference data and reward modeling

Let qpref​(x,y+,y−) be a fixed dataset of preference triples: a prompt x, a preferred response y+, and a rejected response y−. A scalar reward model Rϕ​, with parameters ϕ, defines

Pϕ​(y+≻y−∣x)=σ(Rϕ​(x,y+)−Rϕ​(x,y−)),​(54)

where σ(z)=1/(1+e−z) is the logistic sigmoid. Thus Pϕ​ is the model’s probability that y+ is preferred to y−.

The reward-model loss is

LRM​(ϕ)=−E(x,y+,y−)∼qpref​​logPϕ​(y+≻y−∣x).​(55)

This is not a policy-gradient loss. The preference dataset is fixed, the optimized parameters are ϕ, and the logarithm acts on the predicted preference probability. The result is a reward model that assigns scalar scores to complete responses.

Direct Preference Optimization

For a prompt x and complete response y, let R(x,y) be the sequence score defined in Section 2. The derivation uses this score to connect the online objective to preference probabilities; DPO training will eliminate it from the loss. Let πref​(y∣x) be a fixed reference LLM, and let β>0 control the penalty for moving away from that reference. To derive the optimum, first treat π(y∣x) as any normalized conditional distribution over complete responses. The trainable LLM πθ​ will be substituted afterward. The KL-regularized objective is [3]

Jβ​(π)=Ex∼q​[y∑​π(y∣x)(R(x,y)−βlogπref​(y∣x)π(y∣x)​)].​(56)

Equation (56) is maximized; it is not a loss to be minimized. If π moves farther from πref​, the KL divergence grows and the subtraction makes Jβ​ smaller. Equivalently, one may minimize

Lβ​(π)​=−Jβ​(π)=−Ex∼q,y∼π(⋅∣x)​[R(x,y)]+βEx∼q​DKL​(π(⋅∣x)∥πref​(⋅∣x)).​(57)

In the loss, moving away makes the positive KL term larger. Larger β therefore keeps the policy closer to the reference; smaller β lets the reward dominate.

Equation (57) is the loss for online RL with an explicit reward R(x,y). It is not the DPO loss. Optimizing it requires sampling responses from π and evaluating their rewards. DPO instead uses fixed preference triples (x,y+,y−) and optimizes the pairwise loss below. The two losses are not added together.

For each fixed prompt, maximizing Eq. (56) over normalized response distributions gives

Z(x)π∗(y∣x)R(x,y)R(x,y+)−R(x,y−)​=y∑​πref​(y∣x)exp(βR(x,y)​),=Z(x)πref​(y∣x)​exp(βR(x,y)​),=βlogπref​(y∣x)π∗(y∣x)​+βlogZ(x),=β[logπref​(y+∣x)π∗(y+∣x)​−logπref​(y−∣x)π∗(y−∣x)​].​(58)

The factor Z(x) enforces ∑y​π∗(y∣x)=1. It is constant when two responses to the same prompt are compared, so it cancels in the last line. DPO substitutes that reward difference into Eq. (54) and replaces π∗ by the trainable policy πθ​. The resulting loss is

LDPO​(θ)=−E(x,y+,y−)∼qpref​​logσ(β[​logπref​(y+∣x)πθ​(y+∣x)​−logπref​(y−∣x)πθ​(y−∣x)​]).​(59)

This loss is minimized over θ; β, πref​, and the preference triples are fixed. Its bracket is the preferred response’s log-probability change relative to the reference minus the corresponding change for the rejected response. DPO therefore needs no explicit reward evaluation or on-policy response generation during an update.
