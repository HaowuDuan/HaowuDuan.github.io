LLM Notes · Chapter 1

Modern LLM Architecture

Attention, normalization, and sparse mixture-of-experts layers in decoder-only Transformers.

Primary resources. The two major resources are the Microsoft AI technical report MAI-Thinking-1: Building a Hill-Climbing Machine (Microsoft AI Team 2026) and Lectures 3 and 4 of Stanford’s CS336, Language Modeling from Scratch, taught by Tatsunori Hashimoto (Hashimoto 2026b, 2026a). The MAI report supplies the reference architecture; the Stanford lectures supply the hyperparameter framing. Original papers are cited for individual methods.

Attention

One causal attention head

The batch size is B, and b∈{1,…,B} labels one batch element. A token sequence is a one-dimensional lattice with sites i=1,…,S. At site i, the token is represented by a vector ei(b)​∈Rdmodel​. With additive positional encoding, a position vector pi​∈Rdmodel​ is added at the same site: xi(b)​=ei(b)​+pi​,xi(b)​∈Rdmodel​.(1) Stacking the site vectors gives X(b)∈RS×dmodel​.

Equation (1) is additive positional encoding. RoPE instead rotates projected queries and keys; see Section 1.2.

An attention head maps three matrices Q,K,V to one matrix H. For one head of width dh​, the projection matrices are WQ​,WK​,WV​∈Rdmodel​×dh​ and define Qim(b)​Kjm(b)​Vjm(b)​​=r=1∑dmodel​​Xir(b)​(WQ​)rm​,=r=1∑dmodel​​Xjr(b)​(WK​)rm​,=r=1∑dmodel​​Xjr(b)​(WV​)rm​,​Q(b)K(b)V(b)​∈RS×dh​,∈RS×dh​,∈RS×dh​.​​(2)(3)(4)​ For the rest of the one-head calculation, fix b and suppress its label, so Q,K,V∈RS×dh​. Their i th rows, qi​, ki​, and vi​, are the query, key, and value at token position i. The head output is obtained in four steps: Aij​Λij​Pij​Him​​=dh​​1​m=1∑dh​​Qim​(KT)mj​,=Aij​+Mij​,=∑j′=1S​exp(Λij′​)exp(Λij​)​,=j=1∑S​Pij​Vjm​.​​(5)(6)(7)(8)​ Here (KT)mj​=Kjm​, A,Λ,P∈RS×S, and H∈RS×dh​. The notation is:

Aij​ scaled attention score before masking,
Λij​ masked attention logit passed to softmax,
Pij​ normalized attention weight (or attention probability).

For a causal head, Mij​={0,−∞,​j≤i,j>i.​ Therefore Pij​=0 when j>i. For fixed i, the remaining Pij​ are non-negative and sum to one, so Hi​ is a weighted average of the current and earlier value vectors. This is causal self-attention.

The head width dh​ does not have to equal dmodel​. Restoring the batch label, the output projection A(X(b))=H(b)WO​∈RS×dmodel​,WO​∈Rdh​×dmodel​(9) maps the head output back to the residual-stream width.

From one head to multiple heads

A multi-head layer contains nq​ query heads, labelled h∈{1,…,nq​}. The head label is written as a superscript. For the fixed batch element b, the input to the attention layer is Z(b)∈RS×dmodel​. The index r∈{1,…,dmodel​} labels an input component, and m∈{1,…,dh​} labels a component within one head. In ordinary multi-head attention, head h has projection matrices WQ(h)​,WK(h)​,WV(h)​∈Rdmodel​×dh​. They produce Qim(b,h)​Kjm(b,h)​Vjm(b,h)​​=r=1∑dmodel​​Zir(b)​(WQ(h)​)rm​,=r=1∑dmodel​​Zjr(b)​(WK(h)​)rm​,=r=1∑dmodel​​Zjr(b)​(WV(h)​)rm​,​Q(b,h)K(b,h)V(b,h)​∈RS×dh​,∈RS×dh​,∈RS×dh​.​​(10)(11)(12)​ The sum contracts the input index r. The head label h is not summed: it specifies which projection matrix is used.

The one-head calculation is applied separately for every h: Aij(b,h)​Λij(b,h)​Pij(b,h)​Him(b,h)​​=dh​​1​m=1∑dh​​Qim(b,h)​((K(b,h))T)mj​,=Aij(b,h)​+Mij​,=∑j′=1S​exp(Λij′(b,h)​)exp(Λij(b,h)​)​,=j=1∑S​Pij(b,h)​Vjm(b,h)​.​​(13)(14)(15)(16)​ Since ((K(b,h))T)mj​=Kjm(b,h)​, each head produces H(b,h)∈RS×dh​. Placing the outputs side by side gives Hcat(b)​=[H(b,1)∣⋯∣H(b,nq​)]∈RS×(nq​dh​).(17) The output projection returns to the residual-stream width: A(Z(b))=Hcat(b)​WO​∈RS×dmodel​,WO​∈R(nq​dh​)×dmodel​.(18)

The combined head width nq​dh​ does not have to equal dmodel​. Most models nevertheless use ρhead​=dmodel​nq​dh​​≃1.(19) Placing the query projections side by side gives WQflat​=[WQ(1)​∣⋯∣WQ(nq​)​]∈Rdmodel​×(nq​dh​). One matrix product computes all query heads: S×dmodel​Z(b)​​⋅dmodel​×(nq​dh​)WQflat​​​=S×(nq​dh​)Qflat(b)​​​(20) The h th block of dh​ columns in Qflat(b)​ is Q(b,h). Even when ρhead​=1 makes WQflat​ square, each output component is a linear combination of all dmodel​ input components.

Attention inside a decoder block

The decoder contains L blocks, indexed by ℓ∈{0,…,L−1}. For the fixed batch element b, the residual stream at layer ℓ is Xℓ(b)​∈RS×dmodel​, where S is the number of token positions and dmodel​ is the model width. A standard serial, pre-normalized decoder block acts independently on each batch element (Vaswani et al. 2017): Uℓ(b)​Xℓ+1(b)​​=Xℓ(b)​+Aℓ​(Nℓattn​(Xℓ(b)​)),=Uℓ(b)​+Fℓ​(Nℓffn​(Uℓ(b)​)),​​(21)(22)​

The superscript (b) is a batch label. Within one batch element, i∈{1,…,S} labels position and r∈{1,…,dmodel​} labels residual coordinate, so an entry is (Xℓ(b)​)ir​. Every branch returns to S×dmodel​ before residual addition.

In Equations (21)–(22), A is causal self-attention, F is a dense FFN or MoE layer, and N is usually RMSNorm.

This is a serial block because the FFN reads the attention-updated Uℓ​. In a parallel block, both branches read Xℓ​: Xℓ+1​=Xℓ​+Aℓ​(Nℓ​(Xℓ​))+Fℓ​(Nℓ​(Xℓ​)).(23) The parallel branches can run concurrently. A model using this form must state whether they share Nℓ​ (Hashimoto 2026b).

Depth and width are separate hyperparameters. Their commonly quoted aspect ratio is ρaspect​=Ldmodel​​∼100–200.(24) The range is empirical. Since block ℓ+1 needs the output of block ℓ, increasing L adds serial work and latency (Hashimoto 2026b).

Key/value heads and the KV cache

Fix one batch element and suppress its label. The input to the attention layer is Z∈RS×dmodel​. The numbers of key and value heads are nk​ and nv​, respectively. Their indices are a∈{1,…,nk​},c∈{1,…,nv​}. Their projection matrices and outputs are WK(a)​WV(c)​​∈Rdmodel​×dh​,∈Rdmodel​×dh​,​K(a)V(c)​=Z⋅WK(a)​∈RS×dh​,=Z⋅WV(c)​∈RS×dh​.​​(25)(26)​ Standard multi-head attention (MHA), grouped-query attention (GQA), and multi-query attention (MQA) use nk​=nv​ and pair K(a) with V(a). The two matrices in a pair are not equal; they are produced by different projections.

In MHA, nk​=nv​=nq​, and query head h uses K(h) and V(h). In GQA, 1<nk​=nv​<nq​, and several query heads use the same key and value heads. In MQA, nk​=nv​=1, and every query head uses K(1) and V(1) (Ainslie et al. 2023).

For example, take nq​=8 and nk​=nv​=2. Assign query heads 1–4 to the first key and value heads, and query heads 5–8 to the second. The attention operations are h=1,…,4:h=5,…,8:​Λ(h)=dh​​Q(h)(K(1))T​+M,Λ(h)=dh​​Q(h)(K(2))T​+M,​H(h)=P(h)V(1),H(h)=P(h)V(2).​(27)

During autoregressive inference, the prompt is known before the model runs; each output token becomes the input used to compute the next. This creates two phases.

Prefill.

At the start of a request, the model processes all prompt positions in parallel under the causal mask. This one pass fills the KV cache and produces the vocabulary logits for the first output token.

Decoding.

After the first output token is selected, the model processes one new position per step until generation stops. Its query attends to the cache; its key and value are appended to the cache. The output logits select the next token. The query is discarded because it is not reused.

At one layer, every stored position contains nk​ key vectors and nv​ value vectors, each with dh​ components. For B sequences and S stored positions, the total number of cached scalars is Ncache​=BS(nk​+nv​)dh​.(28)

Decoding speed.

Every generated token rereads the cache. When decoding is memory-bound, smaller Ncache​ moves fewer bytes and is faster. Sharing key and value heads reduces Ncache​ (Hashimoto 2026b).

Full and sliding-window attention

Full causal attention lets position i attend to all j≤i. A sliding window of width w restricts this to i−w<j≤i. The cost becomes O(Swdh​) per head, and the local KV history is bounded by w (Beltagy et al. 2020).

A hybrid pattern can repeat three local layers followed by one full layer. Each layer type may use RoPE or no positional encoding (NoPE). NoPE applies no position-dependent vector, bias, or rotation; the causal mask remains (Hashimoto 2026b). Specify w, the full-layer set, each layer’s positional rule, and KV-cache eviction. These determine receptive field and cache memory.

Normalization placement

For a vector x∈RD, LayerNorm re-centers and re-scales, LN(x)=γ⊙σ2+ϵ​x−μ​+β,μ=D1​r=1∑D​xr​,σ2=D1​r=1∑D​(xr​−μ)2.(29) RMSNorm keeps only the rescaling operation (Zhang and Sennrich 2019): RMSNorm(x)=γ⊙D−1∑r=1D​xr2​+ϵ​x​.(30) RMSNorm omits mean subtraction and usually the bias β; the componentwise gain γ∈RD remains. A bias-free Transformer also uses y=Wx, not y=Wx+b, in attention and FFN projections.

Both norms read and write D components. LayerNorm also reduces and subtracts the mean. Removing those operations can make a memory-bound RMSNorm kernel faster, although both costs are O(D) (Hashimoto 2026b).

An attention or FFN calculation produces an update vector, which is added to the unchanged input vector. Figure 4 shows the three possible positions of the normalization operation.

At update ℓ, xℓ​∈RD is the input vector. The symbol Sℓ​(⋅) denotes the attention or FFN calculation, and Sℓ​(xℓ​)∈RD is the update vector it produces. To see how normalization placement behaves as depth increases, hold the placement fixed and use it at every update, as in Figure 5. The Sℓ​ have different weights; only the pre-norm, post-norm, or sandwich-norm construction is repeated.

Repeating the normalization rule through depth changes the vector passed from one update to the next. Track its size with rms(v)≡D1​vTv​,rℓ​≡rms(xℓ​). In the scaling calculation below, normalization means division by this RMS; learned gains and ϵ are suppressed.

Training sends the loss gradient backward through the same stack. To see how the normalization rule affects it, change the input to update ℓ by a small amount δxℓ​. To first order, δxℓ+1​≃Jℓ​δxℓ​,Jℓ​≡∂xℓ​∂xℓ+1​​∈RD×D. After the full stack in Figure 5, δxL​≃JL−1​⋯J1​J0​δx0​,∇x0​​L=J0T​J1T​⋯JL−1T​∇xL​​L. The second equation is backpropagation through the same stack. The product of all layer Jacobians, rather than one Jℓ​, therefore determines whether a gradient is preserved, suppressed, or amplified as depth increases.

Pre-norm

Pre-norm divides the input to Sℓ​ by rℓ​: fℓ​=Sℓ​(xℓ​/rℓ​). At initialization, suppose rms(fℓ​)≃s and D−1xℓT​fℓ​≃0. Then xℓ+1​rℓ+12​​=xℓ​+fℓ​,=rℓ2​+s2+D2​xℓT​fℓ​≃rℓ2​+s2,​​(31)(32)​ Iterating gives xℓ​=x0​+k=0∑ℓ−1​fk​,rℓ2​≃r02​+ℓs2,rℓ​∼ℓ​.(33) Substituting this result into the pre-norm Jacobian makes its depth dependence explicit: Jℓpre​​=I+Sℓ′​(rℓ​xℓ​​)rℓ​1​(I−Drℓ2​xℓ​xℓT​​)≃I+r02​+ℓs2​1​Sℓ′​(r02​+ℓs2​xℓ​​)(I−D(r02​+ℓs2)xℓ​xℓT​​).​(34) If Sℓ′​ does not grow with depth, then for ℓ≫r02​/s2, Equation (34) further reduces to Jℓpre​≃I+sℓ​1​Sℓ′​(sℓ​xℓ​​)(I−Dℓs2xℓ​xℓT​​)=I+O(ℓ−1/2). The identity I gives the gradient a direct path from xℓ+1​ to xℓ​. The second term describes how layer ℓ changes a small input perturbation. The matrix in the final parentheses cannot increase a vector’s length. The large-depth expression therefore shows directly that Jℓpre​ approaches I: later layers change their inputs by a smaller fraction and are underutilized.

Post-norm

Post-norm first forms uℓ​=xℓ​+Sℓ​(xℓ​) and then divides the sum by its RMS: xℓ+1​=rms(uℓ​)uℓ​​,rℓ+1​=1.(35) The derivative of this division is ∂u∂​(rms(u)u​)=rms(u)1​(I−Drms(u)2uuT​).(36) Therefore Jℓpost​=rms(uℓ​)1​(I−Drms(uℓ​)2uℓ​uℓT​​)(I+Sℓ′​(xℓ​)).(37) To see what Equation (35) does during backpropagation, write gℓ​≡∇xℓ​​L. Then gℓ​=(I+Sℓ′​(xℓ​))T(I−Drms(uℓ​)2uℓ​uℓT​​)rms(uℓ​)gℓ+1​​. The middle matrix removes the component parallel to uℓ​. For example, if uℓ​/∥uℓ​∥=(1,0)T, then I−Drms(uℓ​)2uℓ​uℓT​​=(00​01​); the projector removes the first component before the surviving component is transformed by (I+Sℓ′​)T and scaled by 1/rms(uℓ​).

The gradient-length change at layer ℓ is cℓ​≡∥gℓ+1​∥∥gℓ​∥​. Across the full depth stack, ∥gL​∥∥g0​∥​=ℓ=0∏L−1​cℓ​. If cℓ​≃c<1, the product behaves as cL→0; if cℓ​≃c>1, it behaves as cL→∞. The projector can only suppress a gradient. Explosion comes from the combined rescaling by 1/rms(uℓ​) and (I+Sℓ′​)T. Ordinary post-norm has no identity path that bypasses these factors.

Sandwich norm

Sandwich norm divides both the input to Sℓ​ and its output by their RMS values: fℓ​=rms(Sℓ​(xℓ​/rℓ​))Sℓ​(xℓ​/rℓ​)​,xℓ+1​=xℓ​+fℓ​.(38) Now rms(fℓ​)=1. At initialization, D−1xℓT​fℓ​≃0, and hence rℓ+12​≃rℓ2​+1,rℓ​∼ℓ​.(39) Its Jacobian has the form Jℓsandwich​=I+∂xℓ​∂fℓ​​.(40) The identity I preserves the direct gradient path, while output normalization prevents a single update from becoming arbitrarily large. This is why sandwich norm is used: it keeps the direct gradient path and controls the size of every update (Microsoft AI Team 2026). Equation (39) still gives rℓ​∼ℓ​ because unit-RMS updates accumulate. This is controlled growth of the residual-stream RMS, not a separate instability.

Attention-score stability: QK normalization and soft-capping

Together, QK normalization and soft-capping are a preventive measure that tames the effect of abnormally large attention scores.

Fix query head h and its associated key/value head a, and suppress the batch index. Let qi(h)​ be the query vector at position i and kj(a)​ the key vector at position j. The scaled attention score is Aij(h)​=dh​​(qi(h)​)Tkj(a)​​=dh​​∥qi(h)​∥∥kj(a)​∥​cosθij​,(41) where θij​ is the angle between the two vectors. Since ∣cosθij​∣≤1, controlling the two norms controls the score magnitude.

QK normalization prevents the norms in Equation (41) from setting an arbitrarily large score scale (Dehghani et al. 2023; Wortsman et al. 2023): q​i(h)​Aij(h)​​=RMSNorm(qi(h)​),=dh​​(q​i(h)​)Tkj(a)​​.​kj(a)​​=RMSNorm(kj(a)​),(43)​(42) With unit RMSNorm gain and negligible ϵ, both normalized vectors have norm dh​​; hence ∣Aij(h)​∣≤dh​​. Learned gains modify this bound.

Soft-capping imposes an independent bound with scale c>0: Aijcap,(h)​=ctanh(cAij(h)​​).(44) Its action is explicit: ​Aijcap,(h)​​<c,Aijcap,(h)​=Aij(h)​−3c2(Aij(h)​)3​+O(c4(Aij(h)​)5​)when ∣Aij(h)​∣≪c. At the cap scale, Aijcap,(h)​=ctanh(1)≃0.762c when Aij(h)​=c; for ∣Aij(h)​∣≫c, the result approaches csgn(Aij(h)​). The map is therefore nearly the identity for ordinary scores, compresses scores of order c, and saturates extreme scores at ±c. Apply it before adding the causal mask (Hashimoto 2026b).

Mixture of Experts

An MoE layer is an FFN with a choice. It stores many FFNs, called experts, but runs only a few for each token. Everything important follows from that one idea: more stored capacity at roughly fixed active expert compute, plus a routing problem that must be trained and implemented efficiently.

The practical goal is better quality for a fixed active-compute budget. Controlled studies repeatedly find that increasing sparse capacity can lower held-out loss without increasing the number of expert FFNs run per token. Two representative results from Lecture 4 establish the big picture:

Study Comparison Reported result
Switch Transformer (Fedus et al. 2022) Sparse models with more experts at comparable training compute. Lower test loss; one reported setup reached its target loss about 7× sooner.
OLMoE (Muennighoff et al. 2024) A 1.3 B-active, 6.9 B-total MoE against a 1.3 B dense model, trained on the same 128 H100 GPUs. Roughly 3× fewer FLOPs or tokens and 2× less wall-clock time to the benchmark level shown in the study.

This is the precise sense in which MoE can be faster to train: it may reach a target quality with less training compute or time. A single MoE step is not automatically faster. Sparse kernels, expert balance, and device-to-device communication determine whether the theoretical saving becomes a wall-clock saving (Hashimoto 2026a).

The trade is simple: MoE buys more parameters and often better compute efficiency, but costs more memory, more complicated distributed execution, and a router that can become imbalanced or unstable.

What one expert computes

One expert is the entire FFN map Fe​ in Equation (45). Its three matrices Wgate(e)​, Wup(e)​, and Wdown(e)​ all belong to expert e. This document uses a SwiGLU FFN: its gate path and content path are multiplied componentwise, then projected back to the residual width: Fe​(x)=Wdown(e)​[SiLU(Wgate(e)​x)⊙(Wup(e)​x)].(45)

The superscript (e) means that every expert has its own three projection matrices. MoE changes only which expert receives the token; it does not change the expert itself or the attention layer (Shazeer 2020; Lepikhin et al. 2020).

How the router picks experts

The mainstream design is token-choice top-k routing: each token scores all experts and chooses its own winners. Expert-choice routing, global matching, hash routing, and reinforcement-learning routers exist, but they are not the standard path in current large language models (Hashimoto 2026a).

In this section, i always indexes tokens and e always indexes experts. For token vector xi​∈Rdmodel​, the router produces one score per expert: ri​=Wr​xi​∈RE,Wr​∈RE×dmodel​.(46) The k largest scores determine the selected expert set Si​=TopK(ri​,k).(47) For selected-softmax routing, softmax over those selected scores gives their mixing weights: gi,e​=∑e′∈Si​​exp(ri,e′​)exp(ri,e​)​,e∈Si​.(48) Finally, run the selected experts and add their weighted outputs: FMoE​(xi​)=e∈Si​∑​gi,e​Fe​(xi​).(49) That is the complete MoE computation.

The most common variants differ only in how many winners are kept and how their weights are formed:

Router Selection and weights Main trade-off
Top-1 token choice (Fedus et al. 2022) Keep one softmax winner. Minimal expert compute and communication; most sensitive to imbalance.
Top-k selected softmax (Jiang et al. 2024) Keep a few logits, then normalize the selected logits as in Equations (47)–(48). More robust mixtures at the cost of running multiple experts.
Sigmoid top-k with load bias (DeepSeek-AI 2024) Rank sigmoid scores after adding per-expert selection biases. Separates routing balance from mixture weights; requires online bias updates.

Across these variants, the core remains score, select, run, combine.

How an MoE is trained

An MoE uses the same next-token loss as a dense Transformer. Routing changes which parameters receive that loss.

Top-k selection has no derivative. For token i, hold the selected set Si​ fixed during backpropagation. The language-model loss then updates the selected experts. Equation (48) updates relative router scores only for k>1. Switch top-1 instead retains the selected expert’s full-softmax probability as its gate, so the router still receives a gradient. The next forward pass computes top-k again from the updated scores, so the selected set can change. Experts outside Si​ receive no gradient from xi​.

Two router problems require extra control. The first is expert collapse: a few experts receive most tokens. The second is large raw router scores. These scores are the logits ri,e​. Softmax cannot see a common offset: softmax(ri​+c1)=softmax(ri​). The offset c can therefore drift without changing the routing probabilities. Large positive offsets reduce numerical headroom in low-precision training. A standard z-loss penalizes the router log-partition: Lz​=T1​i=1∑T​[log(e=1∑E​exp(ri,e​))]2.(50) Inside the sum, the exponential makes the loss sensitive to large router scores: the largest scores rapidly dominate the sum. The outer logarithm then brings the result back from exponential scale to the scale of the router scores. The loss therefore reacts strongly to an excessively large score without itself spanning the enormous range of the raw exponential sum.

The reason for balancing is easiest to see before top-k selection. Let pi,e​ be the router probability for expert e, and average it over the tokens: pi,e​=softmax(ri​)e​,pˉ​e​=T1​i=1∑T​pi,e​.(51) The vector pˉ​ describes how the batch is distributed across experts. To spread that distribution, maximize its entropy, or equivalently minimize Lent​=e=1∑E​pˉ​e​logpˉ​e​.(52) Its minimum is the uniform distribution, pˉ​e​=1/E. The entropy is taken over the batch average pˉ​, not over each token’s distribution pi​. Individual routing decisions can therefore remain sharp. Even so, maximum entropy makes a perfectly even batch distribution the target. That is stronger than necessary: experts may receive unequal traffic as they specialize. The practical goal is only to prevent a few experts from receiving an unusually large share.

The implementation therefore measures the experts actually selected by top-k. Their assignment frequencies are fe​=Tk1​i=1∑T​1[e∈Si​].(53) Thus fe​ supplies the actual selection frequency that is missing from the soft probability distribution pˉ​. Because top-k selection is discrete, fe​ is treated as fixed during backpropagation. A common load-aware penalty is Lbal​=Ee=1∑E​fe​pˉ​e​.(54) When the hard assignment frequencies follow the mean probabilities, fe​≈pˉ​e​, this behaves like E∑e​pˉ​e2​: a quadratic penalty for a concentrated distribution. Its formal minimum is also uniform, but large components dominate the quadratic penalty while small components contribute little. With a small coefficient α, it therefore acts mainly against unusually large expert usage rather than enforcing a perfectly even distribution. The factors remain separate because fe​ measures the actual discrete load, while pˉ​e​ supplies the gradient to the router (Fedus et al. 2022; Qiu et al. 2025; Hashimoto 2026a).

With both auxiliary losses defined, the full objective is L=LLM​+αLbal​+βLz​,(55) Here, LLM​ is the usual cross-entropy loss. The coefficients α and β control the strengths of the balance loss and the z-loss.
